Release History

Each saved iteration uses semantic-style version naming so QA feedback can point to a known snapshot. Backups live in the local Backups folder.

5.x Theme And Launcher Branch
Version 5.9 June 4, 2026
  • Separated the changelog tree so 5.x releases live under their own branch instead of the 4.x branch.
  • Preserved the newest-first branch structure so future major versions can be added as their own parent branches.
Version 5.8 June 4, 2026
  • Adjusted the DCS Panels reference palette to give red and yellow stronger presence.
  • Adjusted the GMK Analog Dreams theme and colorway palette to emphasize cyan, yellow, and pink more strongly.
Version 5.7 June 4, 2026
  • Removed DCS Panels from the main theme and keycap colorway dropdowns so only GMK Panels appears as the selectable Panels option.
  • Kept DCS Panels as a reference entry on the Colorway Index page.
Version 5.6 June 4, 2026
  • Renamed Absolute Cream Rainbow to PBTfans Absolute in the main keycap colorway selector.
  • Added theme image-derived palettes to the main Keycap Colorway dropdown and recommendation matching metadata.
  • Added a note that real named theme sets are generally high-end, while lower and mid-tier matches are usually clones or inspired alternatives.
Version 5.5 June 4, 2026
  • Added a Theme Image-Derived Colorways section to the Colorway Index page with palettes and thumbnails from Reference Library/Themes.
Version 5.4 June 4, 2026
  • Added theme presets for the remaining theme reference images: DCS Panels, GMK Analog Dreams, GMK British Racing Green, GMK Copper, GMK Dualshot, GMK Laser, GMK Nervewrecker, and GMK Phoenix.
  • Widened the theme selector to fit the longer theme names without changing during theme swaps.
Version 5.3 June 4, 2026
  • Moved case material from the bottom-right profile tag row into the dynamic selection title.
  • Kept the bottom-right tags focused only on keycap profile characteristics.
Version 5.2 June 4, 2026
  • Moved theme reference images into Reference Library/Themes.
Version 5.1 June 4, 2026
  • Added a no-console Windows Script launcher that opens the configurator without flashing a command prompt.
  • Added a Windows shortcut launcher with a custom top-left page mark icon recolored with the GMK Panels palette.
  • Moved the obsolete batch launcher into a Previous Launchers folder.
  • Recorded the theme direction that text boxes and controls may use accent colors when it strengthens the selected colorway while preserving contrast.
Version 5.0 June 4, 2026
  • Rebalanced the GMK Olivia page theme toward darker modifier tones with deeper page surfaces, stronger dark background motifs, and light readable controls.
