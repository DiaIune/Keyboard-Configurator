Release History

Each saved iteration uses semantic-style version naming so QA feedback can point to a known snapshot. Backups live in the local Backups folder.

Version 2.4 June 4, 2026

  • Consolidated the keycap recommendation heading with the selected budget-tier explanation.
  • Consolidated the keyboard recommendation heading with the selected budget-tier explanation.
  • Removed obsolete main-page CSS from the old inline layout, colorway, and profile indexes.
  • Defined defaults, budget ranges, layout lookup, case-color lookup, and recommendation matching presets up front.
  • Reduced repeated update work by avoiding case-color dropdown rebuilds except when material changes and by reusing normalized recommendation tag sets.

Version 2.3 June 4, 2026

  • Added a budget range dropdown to the main configurator.
  • Changed keycap and keyboard recommendations on the main page to show only the selected budget tier.
  • Moved the layout, colorway, and profile indexes to separate reference pages.
  • Added full keycap and keyboard option table pages behind the top-right navigation.
  • Made collapsed section ribbons more compact for future reference sections.

Version 2.2 June 4, 2026

  • Corrected keycap recommendation naming so JTK and KAP are treated as brands/series.
  • Moved Flight, Brittle, and Grey Alert into copy as specific colorway examples rather than line names.

Version 2.1 June 4, 2026

  • Added the changelog page and top-left changelog link.
  • Started versioned backups using the Backups folder.
  • Expanded keycap recommendations to consider GMK, Domikey, JTK, DCS/Signature Plastics, Keyreative/Keycreative, Milkyway, PBTfans, NicePBT, and CannonCaps.
  • Added vendor-aware recommendation links for NovelKeys, CannonKeys, Divinikey, Unikeys, KBDfans, and related search paths.
  • Updated keyboard recommendations to score layout, material, and case color fit.

Version 2.0 June 4, 2026

  • Baseline backup after theme selector work, Panels contrast fixes, and layout-preview background cleanup.
  • Preserved the working Keyboard Configurator page and launcher before the v2.1 recommendation/changelog update.
