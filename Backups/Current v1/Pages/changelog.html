Release History

The changelog has been reset to track the current configurator from a clean baseline. Prior prototype notes and obsolete process history were removed so future entries stay focused on shipped user-facing changes.

Version 1.0

June 9, 2026
  • Established the current keyboard configurator as the new baseline release.
  • Uses dynamic 2D keyboard layout models with swappable visual parameters for layout, case, keycap colorway, legends, profile, switches, WKL blockers, and sound target.
  • Includes reference pages for layouts, profiles, keycap/colorway direction, build gallery, board options, keycap options, and this refreshed changelog.
  • Applies the selected UI theme consistently across the configurator and reference pages without tying it to the selected keycap colorway.
  • Uses the cleaner load behavior: early theme application, stable system typography, no Google Font reflow on the live pages, and reduced late header changes.
  • Restarts the changelog process so future releases can be recorded from this current version forward.
